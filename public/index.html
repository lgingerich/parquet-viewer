How a Parquet file is organized

  • Row groupA horizontal slice of the table. Row groups are stacked: each holds the next batch of rows.
  • Column chunkOne column's values for one row group, stored contiguously. A cell in the grid above.
  • PageThe unit of encoding and compression. A chunk is a stack of pages, optionally led by a striped dictionary page.
  • FooterWritten last: schema, offsets, sizes and statistics. Readers start here to find everything else.
